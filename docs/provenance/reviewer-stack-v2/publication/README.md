# Published review descriptions

These are the exact 64 PR bodies and the publisher manifest after creation. Body SHA-256 values match the manifest. Original absolute paths identify the operator files used for publication; the copies alongside this README preserve their bytes. To publish elsewhere, render a fresh manifest from the frozen stage index and exact qualification evidence instead of treating historical paths as current inputs.

Only the four foundation PRs are ready; the other sixty remain draft. Publication never merges a PR or automatically advances readiness. The [single overview](../../reviewer-stack-v2.md) contains the complete graph and snapshot mapping.

The independent remote audits verify full head/base SHAs, exact body hashes, readiness and open/unmerged state for all 64 replacement PRs. `superseded-final-state.json` records closure of the seven old PRs without merging. Hosted CI is a timestamped observation, separate from local qualification; pending checks are not passes. Evaluation PR metadata is captured at the time of its description update, before this final publication-record commit.
