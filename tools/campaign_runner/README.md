
## Test ownership after relocation

The standard evaluation command `python3 -m unittest discover -s test -v` loads
the relevant campaign runner regressions through `test/test_campaign_runner.py`.
Four old Make-registry/oracle-pin modules are retained byte for byte as archival
inputs, rather than run against a nonexistent historical Makefile here. Current
source registration/rebuild/optional/C++23/pin contracts are tested by the
library's `test/test_infrastructure.py`. The relocation inventory records their
original bytes; copying the files does not claim their old build environment
exists in this runner directory.
